# tv

TV WebApp for the Teamfit interactive fitness platform.

Die App läuft auf dem SmartTV des Studios, zeigt die Session-Screens T1–T7
und wird über Supabase mit der Smartphone-WebApp synchronisiert. Sie ist
reine Ausgabe (keine direkte Bedienung) und treibt als Session-Treiber die
Zeitachse der Session.

Architektur-Details: [doc/3-TV.md](../../doc/3-TV.md)
